# 실제로 들린 말 = 올바른 말.
#
# 발음 유사도로 못 잡는 자리에만 적는다. 같은 녹음에서 "치매"를 네 엔진이
# 전부 다르게 틀렸는데 유사도 1위가 전부 엉뚱했다.
#
#   치밀하고 -> 치매약 0.500    치고 -> 치매약 0.545
#   짐으로   -> 이명   0.500    심이 -> 이명   0.600
#
# 기준을 낮추면 치매 대신 치매약(약품란!)과 이명이 들어온다. 두 글자 용어라
# 사전 근거만으로는 고치지 않는 규칙에도 걸린다. 들린 말을 적는 수밖에 없다.
#
# 다른 뜻으로도 쓰이는 말은 적지 않는다. "치고"는 "~치고는"이 있어서 뺐다.
# 교정은 제안일 뿐 덮어쓰지 않지만, 운영자를 헷갈리게 하면 안 된다.
